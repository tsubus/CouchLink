## Runtime contract decisions resolved in refinement

1. **Broadcast destinations:** preserve global broadcast plus every currently active interface-specific broadcast. Selection changes payload address/details only.
2. **No-selection wire behavior:** change the advertiser factory contract to return an explicit no-advertisement result. The advertiser skips serialization and all sends for that interval; no sentinel address is serialized.
3. **Atomic address/MAC identity:** the controlled inventory returns one immutable identity containing adapter ID, address, broadcast, and MAC. Runtime snapshot and advertisement read the same lock-protected selected identity. Host/pairing identity and selected-MAC Wake semantics remain unchanged.
4. **Compile-safe snapshot shape:** replace the flat positional address input with one non-null contained `HostNetworkSelectionSnapshot`; nullable selected address/ID and explicit availability/reselection fields represent loss. Update the runtime producer and sole active WPF consumer together.
5. **Test execution:** use a dependency-free executable Host Core test project with named groups, invoke every group explicitly, reject unknown groups, and then run solution tests/WPF build. This avoids adding packages and avoids falsely assuming `dotnet test` executes console assertions.

All task entries now start `status: failing`, carry `risk` and Allure metadata, run tests before implementation within each behavior task, and retain runnable verification commands.
